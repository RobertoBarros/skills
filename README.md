# Minhas Skills

Este repositório reúne minhas skills reutilizáveis para agentes de IA, incluindo Codex e Claude Code.

Cada pasta na raiz representa uma skill independente. O arquivo `SKILL.md` contém as instruções principais; pastas adicionais, como `scripts/`, `references/` e `assets/`, são incluídas apenas quando necessárias.

## Skills disponíveis

- [`tool-pick`](tool-pick/): pesquisa e compara bibliotecas, frameworks, pacotes, CLIs e outras ferramentas de software open source.

As skills seguem o formato `SKILL.md` para permanecerem portáveis entre diferentes harnesses.
